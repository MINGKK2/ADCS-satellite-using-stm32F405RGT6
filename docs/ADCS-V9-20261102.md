# ADCS V9 — dynamic attitude estimation and current PID

Published 2026-11-02, Asia/Bangkok. Firmware `AXIS_FRAME_RP_DYN_V9` was fully
built, flashed by USB DFU and verified. Sector 11 calibration was unchanged.
The subsequent S3/COM23 check returned V9 telemetry and two STATUS ACKs: 230 FAST
records in 12 seconds (about 19.14 Hz), no sequence gaps, valid IMU, sensor error
zero, calibration source FLASH / measured mask 7 / save status 0. Motors/PID OFF.

## Implemented changes since V4

- Ki=5 on all axes; Kp=28/2.4 and Kd=8, motor signs Roll/Pitch +1 and Yaw -1.
- All three one-channel encoders installed: Roll PA8, Pitch PC6, Yaw PA0;
  25 rising pulses/revolution. RPM remains magnitude monitoring/output limiting,
  not body angle feedback or an active cascade speed loop.
- Missing-pulse shutdown removed (V8); zero RPM alone does not block motor output.
  ESTOP, invalid feedback/rate checks and RPM limits remain. Operator PID request
  is distinct from whether PWM can currently be applied.
- WHO=0x70 sensor path now configures and verifies its separate accel LPF.
  Gyro full scale +/-1000 deg/s (32.8 LSB/deg/s); gyro/accel filter setting 2.
  Accel remains +/-2g, so saved raw accel calibration remains compatible.
- Exact constant-body-rate quaternion propagation; bounded dynamic accel noise
  inflation and stillness recovery. Compass bias learning requires body stillness.
  The provisional 30 mg robustness scale is a design assumption, not a measured
  sensor accuracy. No target is fed into the attitude estimator.
- FAST telemetry includes the measured quaternion from the same sample. The
  viewer consumes it directly, discards corrupt poses and avoids a second pose
  smoothing filter. Added clipping diagnostics, report plots/CSV/PNG/SVG metrics,
  encoder validity/policy status and safe explicit remaining-fault recovery UI.

## Verification and limits

Full build had no compile/link warnings. Host tests cover actual PID/EKF/encoder
functions, UART DMA/parser/protocol, Flash rollback, display quaternion, report
metrics and CAD assets. ELF loads below reserved sector 11.

Actual 12-second stationary peak-to-peak: Roll 0.090, Pitch 0.089, Yaw 0.270 deg.
An additional 180-second quiet capture ranged 0.179 / 0.127 / 0.270 deg.
The confirmed motor-off yaw hand test ranged Roll 0.844 / Pitch 1.263 deg with
peak yaw rate 44.455 deg/s, versus V8 2.701 / 2.833 deg at about 100.984 deg/s.
Because speeds differ, this is not a controlled proof of the improvement ratio.
Final yaw differed about -54.18 deg from the initial sample; gyro integration
also indicated nonzero net rotation. Physical return to an independently marked
heading has not been verified. The unconfirmed later capture is not a completed
marked-return experiment. No motor hold response or absolute angle accuracy was
verified in these V9 tests; compass field consistency/placement remains a limit.

Saved calibration loads without recalibration. Raw board Flash backups are not
published. Synthetic tests and real measurements must not be conflated.
